# Ativação no GrokBot

Instale/disponibilize a pasta `manage-codex` no diretório de skills que o GrokBot carrega e adicione esta regra curta às instruções do agente gerente:

> Quando planejar projetos ou decidir modelo, esforço de raciocínio, orçamento, ferramentas, conectores, uso de API ou delegação no Codex, carregue a skill `manage-codex` antes de executar.

Confirme que o agente consegue ler `SKILL.md` e abrir links oficiais. A skill orienta a decisão, mas não concede permissões, instala conectores ou altera a cobrança. Não copie credenciais para a skill.
