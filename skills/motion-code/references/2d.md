# 2D: Canvas, sprites, Pixi/Phaser, rigs, SVG

## Picking the surface

| Content | Use |
|---|---|
| Few crisp, accessible elements (icons, UI, logos) | DOM / SVG |
| Hundreds–thousands of moving things, particles, games | Canvas 2D → PixiJS (GPU) → Phaser (game framework) |
| Frame-by-frame drawn characters | sprite sheet + frame stepping |
| Cutout/bone character with many clips & blending | Spine runtime, Rive, or DragonBones-style rig |
| Designer-authored, interactive states | Rive state machine |

## Canvas 2D loop (runtime) vs pure render (video/test)

```js
// Keep rendering a pure function of t; the loop only supplies t.
function draw(ctx, t) { /* clear + draw state(t) */ }
const dpr = Math.min(devicePixelRatio, 2)
canvas.width = cssW * dpr; canvas.height = cssH * dpr; ctx.setTransform(dpr, 0, 0, dpr, 0, 0)
let start = null, raf
const loop = now => { start ??= now; draw(ctx, (now - start) / 1000); raf = requestAnimationFrame(loop) }
raf = requestAnimationFrame(loop)          // cleanup: cancelAnimationFrame(raf)
window.__seek = t => { cancelAnimationFrame(raf); draw(ctx, t) }       // for capture --seek
window.__probe = () => ({ y: stateAt(lastT).y })
```
- Interactive physics (player-controlled): fixed timestep accumulator (`while (acc >= 1/120) step(1/120)`), render interpolated; seeded RNG.
- Resize: recompute canvas size on `ResizeObserver`, keep world units independent of pixels.

## Sprite sheets

- Layout: uniform grid (frame w×h divides sheet exactly) or atlas JSON (TexturePacker/Aseprite). Each clip: name, frame list, fps, loop flag, pivot/anchor (usually feet center).
- Frame index from time: `frame = Math.floor(t * fps) % frames.length` (looping) — never "advance one frame per rAF".
- Draw: `ctx.drawImage(sheet, col*w, row*h, w, h, x - ax*w, y - ay*h, w, h)`.
- Pixel art: `ctx.imageSmoothingEnabled = false`, CSS `image-rendering: pixelated`, integer positions and integer scale; animate at 8–12 fps (on twos/threes) while movement can be at 60.
- Validation (common bugs): baseline/anchor jitter between frames (feet bob unintentionally), frame size mismatch, clip transitions popping (start next clip on a matching pose/contact), wrong frame order. Verify with capture `--times` at each frame time + `onion.png` with the anchor fixed; for a sheet image alone, render it into an HTML grid with frame numbers and capture once.
- Pixi v8: `await app.init({ resizeTo: window, antialias: true })`; `new AnimatedSprite(textures)`, `animationSpeed = fps / 60`; `app.ticker.add(tk => update(tk.deltaMS / 1000))`; `app.destroy(true)` on teardown. Use `ParticleContainer` for big particle counts.
- Phaser: `this.anims.create({ key, frames: this.anims.generateFrameNumbers('hero', { start, end }), frameRate, repeat: -1 })`; tweens for non-frame motion.

## 2D rigs / cutout

- Hierarchy: root (position) → hips → spine → chest → neck → head; limbs as chains. Pivot each part at its joint.
- FK keyed per joint with overlap (`child(t) = parent(t − lag)`); IK (2-bone analytic) for planted feet/hands: given hip, target foot, lengths a, b → knee angle via law of cosines.
- Mesh deformation (Spine/Rive) for squash/breathing on organic shapes; avoid scaling bones non-uniformly in long chains (shear).
- Drawn style: tweening between drawings distorts volume — add breakdown keys or swap drawings at extremes instead of tweening everything.

## SVG

- Animate `transform` on `<g>` with `transform-box: fill-box; transform-origin: center` (else origin is the SVG viewport).
- Path morph needs compatible paths (same command structure/point count): GSAP MorphSVG, flubber, or author matching paths.
- Stroke draw-on with `pathLength="1"` (see patterns.md). Many SVG nodes animating → move to Canvas.
- Keep `<title>`/`aria-label` on meaningful graphics; decorative ones `aria-hidden="true"`.

## Parallax / 2.5D

Layer offset = camera offset × depth factor (0 = fixed, 1 = moves with camera). Clamp total travel, disable under reduced motion, never tie to scroll in a way that changes scroll speed.

## Hand-rolled 3D in Canvas (fold/unfold a cube)
Hinged faces: point = hinge + d·(cosφ, sinφ) in the hinge plane; φ 0 → 90 folds, 90 → 180 unfolds flat. Painter-sort faces by mean projected z, fill with the background then stroke. Cull by screen-space winding (shoelace sign) relative to the front face — a hinged face shows its *outside* when its winding is opposite to the front's (flip for faces defined mirrored). Without culling, hidden edges leak past corners as stray ticks.
