# 3D: Three.js, R3F, rigs, cameras

## Time

- Drive everything from one time value. Runtime: `renderer.setAnimationLoop(ms => render(ms / 1000))` (or `THREE.Timer` / legacy `Clock` for delta). Video/tests: `seek(t)` sets every transform/uniform/mixer from t, then `renderer.render(scene, camera)`.
- Frame-rate independent smoothing: `x = THREE.MathUtils.damp(x, target, lambda, dt)` (never `x += (target − x) * 0.1` per frame).
- Shader time uniforms come from t, not an incrementing counter. Seeded RNG for anything random.

## Clips (glTF, skeletal, morph)

```js
const gltf = await new GLTFLoader().setDRACOLoader(draco).loadAsync('/hero.glb')   // three/addons/loaders/...
const mixer = new THREE.AnimationMixer(gltf.scene)
const walk = mixer.clipAction(THREE.AnimationClip.findByName(gltf.animations, 'Walk'))
walk.play()
// runtime: mixer.update(dt)   |   seek: mixer.setTime(t)
// transition: walk.crossFadeTo(run, 0.3, true); one-shot: a.setLoop(THREE.LoopOnce, 1); a.clampWhenFinished = true
```
- Crossfade on matching phase (foot contact) to avoid sliding/popping; sync speeds with `action.timeScale` so stride matches ground speed (root motion vs in-place: if in-place, move the root at stride_length / cycle_time).
- Morph targets (faces, blend shapes): `mesh.morphTargetInfluences[mesh.morphTargetDictionary.smile] = w`. Lip sync: map visemes to targets, ease 40–80 ms between.
- FK for posing chains; IK when contact matters (feet on ground, hand on object): two-bone analytic or `CCDIKSolver` (three/addons/animation). Author complex rigs in Blender, export glTF (bake constraints/IK to keys on export).
- Procedural secondary motion on bones (tail, antenna): apply lagged parent rotation after `mixer.update`.

## Camera language

| Move | Use | Formula / tip |
|---|---|---|
| Orbit | product turntable, reveal volume | `pos = target + d·(sin a·cos e, sin e, cos a·cos e)`; constant angular speed for turntable (linear), ease-in-out for reveals |
| Dolly / push-in | emphasis, tension | move the camera, not FOV; ease-in-out, slow (2–4 s) |
| Dolly zoom (vertigo) | 2D→3D reveal, unease | keep subject height H fixed: `d = H / (2·tan(fov/2))`, animate fov, recompute d each frame |
| Isometric | diorama/clean diagrams | azimuth 45°, elevation 35.264° (`atan(1/√2)`); true iso = OrthographicCamera |
| Truck/pan/crane/tracking | follow action | lead room in the direction of motion; damp the follow (`damp`) to avoid jitter |
| Shake | impact | trauma² × smooth noise on position + small roll (patterns.md) |

Composition beats effects: clear silhouette against background, one focal point, contrast where the eye should go. Post-processing never fixes unreadable staging.

## Rendering defaults

- `renderer.setPixelRatio(Math.min(devicePixelRatio, 2))`; output sRGB (default); textures with color data `tex.colorSpace = THREE.SRGBColorSpace`; tone mapping ACES/AgX for PBR scenes.
- Lighting: key directional + hemisphere/environment fill; shadows `PCFShadowMap` (`PCFSoftShadowMap` is deprecated since r182) with a tight shadow camera; stylized scenes can fake contact shadows with a blurred plane.
- Many identical objects → `InstancedMesh` (`setMatrixAt(i, m)` + `instanceMatrix.needsUpdate = true`); particles → `Points` or instanced quads.
- WebGPU: `import * as THREE from 'three/webgpu'`; `const renderer = new THREE.WebGPURenderer(); await renderer.init()` (falls back to a WebGL2 backend). Shaders via TSL there; keep WebGLRenderer if the project's shaders are GLSL.

## React Three Fiber

- `useFrame((state, delta) => { ref.current.rotation.y += delta * speed })` — mutate refs; never `setState` per frame.
- `<Canvas dpr={[1, 2]} frameloop="demand">` + `invalidate()` for mostly static scenes; drei `useGLTF`, `useAnimations(animations, group)` → `actions.Walk.play()`.
- Version pairing: R3F v9 ↔ React 19, v8 ↔ React 18. Don't move to alpha majors without reason.
- Seekable R3F: components read a shared `timeRef.current` (not `clock`) inside `useFrame`; with `<Canvas frameloop="never">`, `const advance = useThree(s => s.advance)` and `window.__seek = t => { timeRef.current = t; advance(performance.now()) }`. Live mode just sets `timeRef.current += delta`.

## Cleanup & performance

- On teardown: `renderer.setAnimationLoop(null)`, dispose geometries, materials, textures, render targets, `renderer.dispose()`; remove resize/pointer listeners.
- Budget (mobile): draw calls ~≤ 100–200, textures compressed (KTX2/Basis), meshes Draco/Meshopt, shadows on few lights, pause rendering offscreen/hidden.
- Measure with `renderer.info.render.calls/triangles` exposed via `__probe` and with real-time FPS (qa.md).
- Fallback: detect WebGL failure → static poster image; reduced motion → no camera moves/auto-orbit, keep interaction.

## Verify

`capture.mjs --probe` with values like `{ y: ball.position.y, sy: ball.scale.y, fov: camera.fov, dist: camera.position.distanceTo(target) }` → lint checks bounce physics, dolly-zoom invariance (subject screen size constant: project top/bottom points and probe the pixel height), settle times. WebGL in headless Chromium works with `--ignore-gpu-blocklist`; on macOS add `--use-angle=metal` if frames come out black.
